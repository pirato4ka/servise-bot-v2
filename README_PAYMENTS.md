# Оплата через CryptoBot (Бесконечный счет)

## Как получить токен
1. Иди в @CryptoBot (для прода) или @CryptoTestnetBot (для теста)
2. Команда /pay -> Create App (Создать приложение)
3. Вводи название приложения -> получаешь токен вида 12345:ABC...
4. Вставь его в .env -> CRYPTO_BOT_TOKEN

## Логика договорной цены
1. Юзер отправляет анкету
2. Админу в админ-чат приходит заявка с кнопками:
   ✅ Подтвердить заявку | ❌ Отклонить
3. Админ нажимает Подтвердить -> бот просит ввести цену:
   > 100 USDT
   > 0.05 BTC
   > 50 TON
4. Бот создает бесконечный инвойс (без expires_in) через aiocryptopay
   `invoice = await client.create_invoice(asset, amount, description, payload)`
5. Счет улетает юзеру от имени бота (укр интерфейс) + кнопка Оплатить
6. Юзер оплачивает в CryptoBot, потом жмет "Проверить оплату"
7. Проверка через get_invoices -> status == paid
8. Админ тоже может проверить оплату кнопкой в админ-чате

## Бесконечный счет
В CryptoBot если не указывать expires_in, инвойс живет вечно пока не оплатят.
Это идеально для договорной цены — юзер может оплатить через час/день.

## Таблицы БД invoices
- crypto_invoice_id
- user_id, ticket_id
- asset, amount
- bot_invoice_url, mini_app_url
- status: active / paid

## Тестирование
Установи CRYPTO_BOT_IS_MAINNET=False и используй @CryptoTestnetBot для тестов без реальных денег.
